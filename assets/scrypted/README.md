# Scrypted doorbell chime

The file `doorbell-3x.mp3` contains three repetitions of the original doorbell chime with two ~0.78-second pauses, designed to play on Chromecast devices from Scrypted.

Original audio: https://github.com/jonjonsson/SoundMonster/blob/main/Public%20domain/doorbell.mp3 (public domain / CC0).

Use this raw MP3 URL in Scrypted's Play Audio Button script:
https://raw.githubusercontent.com/aarondglover/docs/scrypted-doorbell-assets/assets/scrypted/doorbell-3x.mp3
